PARSING RULES:

material_code:
  - The supplier's internal product or material code.
  - Some invoices (e.g. Asian Paints) stack the material code and HSN in one cell:
      Top line:    the material code  (e.g. "00010210210", "5057IE24122")
      Bottom line: "HSN - 320890" or "HSN-320890"
  - material_code = the top line only. hsn_code = digits from the bottom line.
  - Never put an HSN value into material_code.
  - If the cell only contains "HSN-...", set material_code to null.

description:
  - The full product name as printed.
  - Exclude tax-type annotation lines such as "IN: Central GST OP" or "IN: State GST OP".

quantity:
  - INTEGER count of individual units (cans, bottles, drums, pieces).
  - Use the "Qty" or "Quantity" column, NOT the volume/weight column.
  - Must be a whole number.

num_packs:
  - Count of cartons, drums, or boxes.
  - If the invoice has a "Packs" column, read the numeric part (e.g. "2 DRM" → 2).
  - If no Packs column exists, set num_packs equal to quantity.

pack_size:
  - The pack unit from the Packs column (e.g. "CAR", "DRM", "CAN").
  - If no Packs column exists, use the unit of measure for a single item.

volume:
  - Decimal total weight or volume from a "Volume", "Kg/Lt/M", or similar column.
  - Use 0 if no such column exists.

unit:
  - Unit of measure for the quantity field, exactly as shown on the invoice.
  - For Asian Paints invoices this is always "UNT".

rate_per_pack:
  - Price per pack (carton/drum). If the Rate column stacks rate and GST%,
    the top number is the rate and the bottom number(s) are GST percentages.

unit_rate:
  - Rate per individual unit. If not shown explicitly, calculate: value / quantity.

value:
  - Line gross value before discount: quantity × rate_per_pack (or unit_rate × quantity).

discount_amount:
  - Per-line cash discount in rupees.
  - Values with a trailing "−" (e.g. "83.70-") are positive discounts — store as 83.70.
  - Use 0 if no per-line discount.

discount_percent:
  - Only when the invoice shows a percentage discount on the line. Otherwise use 0.

cash_discount_amount (header):
  - Total fast/cash discount from the invoice summary (e.g. "Fast Cash Discount: 2119.50-" → 2119.50).
  - Often appears only on the last page. Use 0 if not visible on this page.

taxable_amount:
  - value − discount_amount.

hsn_code:
  - Digits only, no "HSN" prefix or slashes. e.g. "320890" not "HSN - 320890".

page_number / total_pages:
  - Read from the page footer, e.g. "Page 1 of 3" → page_number=1, total_pages=3.
  - If not printed, use page_number=1, total_pages=1.

GENERAL RULES:
  - Dates: YYYY-MM-DD format. Use null if missing.
  - All numeric fields must be numbers, not strings. Use 0 if missing.
  - Return items: [] for non-item pages (terms, signature, acknowledgement pages).
  - Do not invent data. Extract only what is visually present on this page.

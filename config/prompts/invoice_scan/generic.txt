════════════════════════════════════════════════════════════
CRITICAL — READ THIS BEFORE EXTRACTING ANYTHING
════════════════════════════════════════════════════════════

These invoices have GST applied ONLY at the invoice footer, NOT per line item.

THE "Amount" COLUMN = pre-GST, post-discount line total.
It is calculated as: quantity × unit_rate × (1 − discount_percent/100)

WHAT TO DO:
  ✓ total_amount  = read the "Amount" column value EXACTLY as printed
  ✓ taxable_amount = same as total_amount
  ✓ discount_percent = read from the "Disc.%" column (see rules below)
  ✗ DO NOT add GST to total_amount
  ✗ DO NOT set cgst_percent / sgst_percent / igst_percent on line items — always 0
  ✗ DO NOT set cgst_amount / sgst_amount / igst_amount on line items — always 0.00

VERIFICATION: sum of all items' total_amount ≈ header.total_taxable_amount (the pre-GST subtotal).
If your sum ≈ header.total_amount (the grand total including GST), you made the error above.

════════════════════════════════════════════════════════════
FIELD RULES
════════════════════════════════════════════════════════════

description:
  Full product name as printed. No HSN codes or tax annotation lines.

quantity:
  Number from the Quantity column.

unit:
  Unit of measure (e.g. "Nos", "pcs", "bgs", "Kgs", "Ltr").

unit_rate:
  Value from the Rate column — the price per unit BEFORE discount.

discount_percent:
  Read from the discount column on the line item row.
  Column header may appear as: "Disc.%"  "Disc %"  "Disc%"  "Discount%"
    "Discount %" "Disc."  "Discount"  — all mean the same field.
  Strip any trailing "%" and store as a plain number:
    "15.254%" → 15.254   "15.254" → 15.254   NOT 0.15254
  OCR artefact: if the value is a whole number > 100 (e.g. "15254") and
    qty × rate × (1 − value/1000/100) ≈ Amount, then use value/1000 (e.g. 15.254).
  Use 0.00 if the column is blank, shows "—", or is absent.

discount_amount:
  Compute: round(quantity × unit_rate × discount_percent / 100, 2)
  Use 0.00 if discount_percent is 0.

total_amount:
  Read DIRECTLY from the "Amount" column as printed.
  DO NOT compute qty × rate × (1 + GST%). That produces the wrong value.

taxable_amount:
  Set equal to total_amount.

cgst_percent / sgst_percent / igst_percent:
  Always 0 for every line item. Never copy the invoice's GST Rate column here.

cgst_amount / sgst_amount / igst_amount:
  Always 0.00 for every line item.

hsn_code:
  Digits only, no "HSN" prefix. e.g. "3208" not "HSN-3208".
  Some invoices have an "MRP/Marginal" column — ignore it.

HEADER total fields:
  total_taxable_amount = the pre-GST subtotal printed in the footer (sum of Amount column).
  total_cgst  = CGST amount from footer (e.g. "OUTWARD CGST 9%: 6,322.87" → 6322.87).
  total_sgst  = SGST amount from footer.
  total_igst  = IGST amount from footer (inter-state only). Use 0 if absent.
  total_amount = grand total as printed (includes GST and rounding).

page_number / total_pages:
  From footer e.g. "Page 1 of 3". Use 1/1 if not printed.

GENERAL RULES
════════════════════════════════════════════════════════════
  - Dates: YYYY-MM-DD. Use null if missing.
  - All numeric fields must be numbers, not strings. Use 0 if missing.
  - Return items: [] for non-item pages (terms, signature pages).

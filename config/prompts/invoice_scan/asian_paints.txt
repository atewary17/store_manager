SUPPLIER: Asian Paints Limited

COLUMN ORDER (Asian Paints invoices):
  Col 1: Material/HSN  — stacked cell: line 1 = material_code, line 2 = "HSN - XXXXXX"
  Col 2: Description   — full product name
  Col 3: Qty           — INTEGER count of individual units → maps to "quantity"
  Col 4: Packs         — packaging unit e.g. "1 CAR", "2 DRM" → numeric part maps to "num_packs"
  Col 5: Volume/Kg/Lt  — decimal volume/weight total → maps to "volume"
  Col 6: Rate/Pack     — price per pack → "rate_per_pack"
  Col 7: Value         — line subtotal before discount → "value"
  Col 8: In-Bill Disc  — in-bill discount (ignore for discount_amount)
  Col 9: Cash Disc.    — per-line cash discount in rupees (trailing "-" means positive) → "discount_amount"
  Col 10: Taxable Amt  — taxable amount after discount → "taxable_amount"
  Col 11+: Tax columns — CGST/SGST/IGST percent and amount

PARSING RULES:

material_code:
  - Asian Paints stacks material_code and HSN in one cell.
  - Line 1 = material_code (e.g. "00010210210", "5057IE24122", "67923558210")
  - Line 2 = "HSN - 320890" or "HSN-320890" — extract digits only → hsn_code
  - NEVER put an HSN value into material_code.
  - If the only value starts with "HSN", material_code = null.
  - Valid examples:  "12601744", "00010210210", "5057IE24122", "67923558210"
  - Invalid examples: "HSN - 320890", "32091090", "321390"

quantity:
  - INTEGER from Col 3 (Qty column). NEVER use the Volume column value.
  - Example: "6 1 CAR 6.000" → quantity=6, num_packs=1, volume=6.000
  - Example: "2 2 DRM 20.000" → quantity=2, num_packs=2, volume=20.000

num_packs:
  - Numeric part from Col 4 Packs field.
  - "1 CAR" → 1,  "2 DRM" → 2,  "4 CAN" → 4

volume:
  - Decimal from Col 5 (Volume/Kg/Lt/M). e.g. 6.000, 20.000, 40.000.
  - Use 0 if no such column exists.

unit:
  - Always "UNT" for Asian Paints (individual units/pieces — cans, drums, etc.).
  - Do NOT use "LT", "KG" or any volume unit here; those belong in the volume field.

discount_amount:
  - Per-line rupee value from Col 9 "Cash Disc." column.
  - Values appear with a trailing "-" e.g. "83.70-" → store as positive 83.70.
  - Do NOT confuse with "In-Bill Disc." (Col 8), which is a separate column.
  - Use 0 if no cash discount on this line.

discount_percent:
  - Use only when the invoice states a percentage discount on the line.
  - If only a rupee discount_amount is shown, set discount_percent to 0.

cash_discount_amount (header):
  - Total fast/cash discount from the invoice summary section.
  - e.g. "Fast Cash Discount: 2119.50-" → 2119.50
  - Often appears only on the last page. If not visible on this page, use 0.

unit_rate:
  - Rate per individual unit. If not shown, calculate: value / quantity.

hsn_code:
  - Digits only, no slashes or "HSN" prefix. e.g. "320890" not "HSN - 320890"
